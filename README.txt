KARACHI KINETIC RICKSHAW - how to run
1. Install Python 3.10+ and Pygame:   py -3.13 -m pip install pygame
2. Replace your whole project folder with this one (keep the assets/vehicles folder next to main.py).
3. Run:   py -3.13 main.py

Controls: D/Right gas | A/Left brake+reverse | Space/W/Up jump | R restart | Esc pause
Garage: Left/Right browse, Enter buy/select, Esc back.   Map screen: Left/Right choose, Enter drive.
Save file: save.json (delete it to reset money and vehicles). For testing set START_WALLET in settings.py and delete save.json.
