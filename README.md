Karachi Kinetic Rickshaw - setup
1. Install Python 3.9+ and run:  pip install pygame
2. Keep main.py, settings.py and ui.py in the same folder.
3. Make a folder called assets next to main.py and put your images in it:
     assets/rickshaw.png    (vehicle facing right)
     assets/background.png  (any size, it is scaled to the window height)
   Missing images are replaced by a green box / a built-in skyline.
4. Run:  python main.py

Menu: Up/Down + Enter, or the mouse.
Game: D/Right accelerate, A/Left brake, Space/W/Up jump, R restart, Esc pause
